# NoBlackBars

Harmony-патч для клиента Space Station 14: убирает чёрные полосы вокруг игрового мира.

## Что делает

`Content.Client.Viewport.ScalingViewport` рисует мир в прямоугольник фиксированных
пропорций (в SS220 это 21×15 тайлов). На 16:9 такая картинка уже окна, поэтому по
бокам остаются чёрные поля. Патч перед созданием вьюпорта подбирает его ширину из
высоты и пропорций контрола, поэтому мир заполняет всё окно.

Масштаб при этом равномерный: картинка не растягивается и не обрезается, просто по
бокам видно больше мира. Дополнительно отключается снап к целому масштабу
(`MainViewport.CalcSnappingFactor`), иначе он снова центрировал бы картинку и
возвращал поля.

Матрица перевода координат мыши строится из того же прямоугольника, так что прицел,
клики и оверлеи остаются согласованными с картинкой.

## Сборка

Нужен .NET SDK 10 и собранный клиент игры. По умолчанию ссылки берутся из
`C:\LocalDutyAVS\bin\Content.Client`; другой путь можно передать так:

```powershell
dotnet build .\NoBlackBars.csproj -c Release -p:GameDir="D:\SS14\bin\Content.Client"
```

Готовая DLL: `bin\Release\net10.0\NoBlackBars.dll`.

## Установка

1. Собрать и установить: `.\build.ps1 -Install` (копирует `NoBlackBars.dll` в
   `%LOCALAPPDATA%\BebraLauncher\patches\` и обновляет `manifest.json`).
2. Открыть лаунчер, вкладка «Моды», включить `NoBlackBars`.
3. Запустить игру.

`patches\manifest.json` хранит SHA-256 и размер файла; лаунчер проверяет их перед каждым
запуском и не загружает изменённый файл (см. `loader/README.md`).

## Ограничения

- Патч завязан на приватные методы `ScalingViewport.RegenerateViewport()` и
  `MainViewport.CalcSnappingFactor()`. Если в новой версии клиента их переименуют
  или удалят, патч просто не применится (игра продолжит работать без него).
- Патч клиентский: серверная логика не меняется, но по бокам становится видно больше
  мира. Ширина вьюпорта подстраивается под текущее окно, в том числе на ультрашироких
  мониторах.
- Если в настройках игры выключить «растяжение вьюпорта» (`viewport.stretch`), снап
  вернётся и поля появятся снова: патч рассчитан на включённый режим растяжения.
