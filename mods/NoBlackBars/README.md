# NoBlackBars

Harmony-патч для клиента Space Station 14: убирает чёрные полосы вокруг игрового мира.

## Что делает

`Content.Client.Viewport.ScalingViewport` рисует мир в прямоугольник фиксированных пропорций
(в SS220 это 21×15 тайлов). На 16:9 такая картинка уже окна, поэтому по бокам остаются поля.
Патч перед созданием вьюпорта подбирает его ширину по высоте и пропорциям контрола, и мир
заполняет окно.

Масштаб равномерный: картинка не растягивается и не обрезается, по бокам просто видно больше мира.
Снап к целому масштабу (`MainViewport.CalcSnappingFactor`) отключается, иначе он снова центрировал
бы картинку. Матрица перевода координат мыши строится из того же прямоугольника, поэтому прицел,
клики и оверлеи совпадают с картинкой.

## Сборка

Нужны: .NET SDK 10, собранный клиент игры и `Lib.Harmony` 2.4.3 в кэше NuGet
(см. [BebraWare](../BebraWare/README.md#сборка)). По умолчанию ссылки берутся из
`C:\LocalDutyAVS\bin\Content.Client`:

```powershell
dotnet build .\NoBlackBars.csproj -c Release -p:GameDir="D:\SS14\bin\Content.Client"
```

Готовая DLL: `bin\Release\net10.0\NoBlackBars.dll`.

## Установка

1. `.\build.ps1 -Install`: копирует `NoBlackBars.dll` в `%LOCALAPPDATA%\BebraLauncher\patches\` и
   обновляет `manifest.json` (SHA-256 и размер).
2. В лаунчере на вкладке «Моды» включите `NoBlackBars`.
3. Запустите игру.

Лаунчер проверяет `manifest.json` перед каждым запуском и не загружает изменённый файл
(см. [loader/README.md](../../loader/README.md)).

## Ограничения

- Патч завязан на приватные методы `ScalingViewport.RegenerateViewport()` и
  `MainViewport.CalcSnappingFactor()`. Если в новой версии клиента их переименуют или удалят,
  патч не применится, игра работает без него.
- Патч клиентский: серверная логика не меняется, но видно больше мира по бокам. Ширина
  подстраивается под окно, в том числе на ультрашироких мониторах.
- Если в настройках игры выключить растяжение вьюпорта (`viewport.stretch`), снап вернётся и поля
  появятся снова: патч рассчитан на включённое растяжение.
