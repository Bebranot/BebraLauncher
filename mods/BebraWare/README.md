# BebraWare

Клиентский Harmony-мод для Space Station 14 (SS220/ADT-форк).

## Что делает

Мод объединяет один безопасный визуальный патч: `ScalingViewport.RegenerateViewport`
получает ширину игрового вьюпорта из фактических пропорций окна, а
`MainViewport.CalcSnappingFactor` отключает целочисленный снап масштаба. Благодаря этому
на широких мониторах исчезают лишние чёрные поля без растяжения по одной оси и без
изменения серверной логики.

Точные классы и методы проверены в текущих сборках `Content.Client.dll`:
`Content.Client.Viewport.ScalingViewport.RegenerateViewport` и
`Content.Client.UserInterface.Controls.MainViewport.CalcSnappingFactor`.

## Безопасность

Исходный файл содержит только Harmony-атрибуты и операции с размерами UI. В нём нет
сети, файловой системы, реестра, процессов, нативных библиотек, перехвата ввода,
скриншотов, чтения токенов или обхода античита. Старый `CerberusWareV3.dll` из соседней
папки не используется: его декомпиляция показала функции aim assist/ESP, блокировку
античита, `MinHook`, нативные загрузчики и работу с чувствительными данными.

## Сборка

Нужен .NET SDK 10 и собранный клиент игры. Из этой папки:

```powershell
.\build.ps1
```

Или с другим расположением клиента:

```powershell
.\build.ps1 -GameDir "D:\SS14\bin\Content.Client"
```

Скрипт выполняет `dotnet build -c Release`. Все игровые DLL и `0Harmony.dll` подключаются
только для компиляции (`Private=false`) и не копируются в выходную папку.

## Установка

```powershell
.\build.ps1 -Install
```

Команда копирует DLL в `%LOCALAPPDATA%\BebraLauncher\patches` и обновляет
`manifest.json` с SHA-256 и размером файла. После этого включите `BebraWare` во вкладке
модов лаунчера.

## Ограничения

- Патч зависит от имён методов текущей версии клиента; при их переименовании Harmony
  не применит соответствующий класс.
- Мод меняет только отображение клиента. Он не даёт доступа к серверным данным и не
  изменяет правила игры.
- Запуск игры этим проектом не выполняется.
