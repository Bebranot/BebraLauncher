# Новости BebraLauncher

Лаунчер читает `news/news.json` из ветки `main` и показывает его на вкладке «Новости» → BebraLauncher.
Сервер не нужен: чтобы опубликовать новость, добавьте запись в файл и запушьте в `main`. Можно прямо на github.com.

У игроков новость появится примерно через 15 минут или после перезапуска лаунчера: файл кеширует GitHub (около 5 минут) и сам лаунчер (10 минут).

## Запись

```json
{
  "id": "open-beta",
  "date": "2026-11-05",
  "title": { "ru": "Заголовок", "en": "Title" },
  "body": { "ru": "Первый абзац.\n\nВторой абзац.", "en": "First paragraph.\n\nSecond paragraph." },
  "link": "https://example.com/details"
}
```

- `id` — обязателен и уникален, потом не меняется: по нему лаунчер отмечает новость как прочитанную.
- `date` — `ГГГГ-ММ-ДД`. По этой дате новости сортируются, новые сверху.
- `title` — обязателен, хотя бы на одном языке. Языки: `ru`, `en`, `uk`, `de`. Если перевода нет, показывается русский текст.
- `body` — необязателен. Это обычный текст: HTML и разметка не работают, абзацы разделяются через `\n\n`.
- `link` — необязательна, только `https://`. Другие ссылки лаунчер отбрасывает.

Запись с ошибкой пропускается, остальные показываются. Если сломан весь файл, игроки продолжат видеть уже скачанный список, а при первом запуске увидят ошибку. Показываются 30 самых новых записей.

## Пока репозиторий закрыт

Без токена GitHub файл недоступен, и игрок увидит «новостей пока нет». С токеном из вкладки «Обновления» лаунчер читает файл через API GitHub. Когда репозиторий станет публичным, новости заработают у всех, менять лаунчер не придётся.
