# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Игроки Space Station 14 на Windows 10/11, которым нужен быстрый и лёгкий лаунчер: поиск серверов, смена аккаунтов, вход в игру без задержек и подвисаний.

## Product Purpose

Лёгкий десктопный лаунчер для Space Station 14: быстрый старт, мгновенный отклик интерфейса, минимум настроек для первого входа и широкая персонализация для тех, кто её хочет.

## Positioning

Rust + Tauri 2 (WebView2) + Svelte 5. Компактный установщик (около 35 МБ), несколько хабов, профили оптимизации клиента, работа с официальными аккаунтами Wizards' Den через Windows Credential Manager, темы и безопасные текстовые пакеты локализации. Полный список возможностей: [README.md](README.md).

## Operating Context

- Запуск перед игровой сессией: онлайн, карта, раунд и пинг серверов на хабах или при прямом подключении.
- Запуск игры через `SS14.Loader` с фоновой загрузкой, проверкой контента. На время игры окно закрывается с освобождением памяти (значок в трее), сворачивание окна — опция.
- Обработка ссылок `ss14://` и redial-запросов игрового клиента.
- Офлайн-режим: кэшированный список серверов при проблемах с сетью.

## Capabilities and Constraints

- **Стек**: Windows 10/11 x64, ядро на Rust (`crates/core`), UI на Tauri 2 + Svelte 5 (`app/`), игровой загрузчик `SS14.Loader` (.NET 10).
- **Безопасность**:
  - Вход только через официальный сервис Wizards' Den, с 2FA.
  - Пароли не сохраняются на диске и не выводятся в логи. Токены лежат в Windows Credential Manager и обновляются автоматически.
  - Обновления и сборки проверяются по Ed25519 (движок, модули, обновления лаунчера).
  - Текстовые пакеты принимаются только если содержат файлы `Locale/<lang>/*.ftl`; код из них не исполняется.
  - Моды-патчи (`.dll`) — осознанно исполняемый сторонний код. Лаунчер хранит SHA-256 установленных файлов, не загружает изменённые, предупреждает и умеет отключить все патчи одним действием. Сервер может счесть их читерством.
- **Интернационализация**: интерфейс на русском (эталонный язык), английском, украинском и немецком (`ru`, `en`, `uk`, `de`). Языки всегда показываются самоназваниями, технические коды скрыты.

## Brand Commitments

- **Название**: BebraLauncher.
- **Дизайн**: чистый, плоский, минималистичный интерфейс без лишних визуальных эффектов. Высокая плотность полезной информации.
- **Привычная компоновка**: вкладки снизу, фильтры и поиск под таблицей серверов, аккаунты и ссылки сообщества в шапке.
- **Кастомизация**: 17 готовых тем и собственная тема с обменом через JSON.

## Product Principles

1. **Мгновенный отклик**: интерфейс открывается и реагирует сразу при любых операциях: поиск и фильтрация сотен серверов, смена темы.
2. **Минимум заморочек**: за несколько секунд можно зайти на любимый сервер без сложной настройки.
3. **Широкая, но ненавязчивая кастомизация**: глубокая настройка внешнего вида, профилей и хабов доступна тем, кому она нужна, и не мешает обычному игроку.
4. **Строгая безопасность**: защита официальных аккаунтов, токены в системном хранилище Windows, проверка подписей контента.
