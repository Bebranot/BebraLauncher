## 6. Что проверено и в порядке

Чтобы не искать это заново:

- **Тесты и статика:** Rust-тесты, UI-тесты, `clippy -D warnings`, `svelte-check` — зелёные на момент ревью (см. §1 и статус).
- **Секреты:** `Token` не реализует `Display`, `Debug` скрыт; в argv токен не попадает; ошибки auth не содержат тела ответа. Утечек токена/пароля не найдено, кроме `describe()` (P1-16) и прокси/хаба (P1-13), которые закрыты.
- **Подпись обновлений:** Ed25519 привязана к `bebra-update:<версия>:<sha256>`; старый установщик под новым тегом не проходит (тест `signatures_bind_version_and_file`). Повторная проверка перед запуском — P2-27 (закрыто).
- **Пакеты:** пакет может содержать только `Locale/<lang>/*.ftl`; `..`, `\`, `:`, ведущий `/`, control-символы и посторонние файлы отклоняют пакет целиком; на диск по путям из пака ничего не пишется.
- **Модули:** `unpack_zip` использует `enclosed_name` + `Component::Normal` — zip-slip закрыт.
- **UI-безопасность:** `{@html}` нигде нет; `open_url` проверяет `http(s)` и длину; цвета своей темы валидируются; XSS/CSS-инъекцию через тему не найдено.
- **Tauri:** CSP строгая (`default-src 'self'`, connect только ipc), capabilities минимальны, токены в UI не передаются.
- **content.db:** схема и имена миграций соответствуют официальному лаунчеру, `PRAGMA journal_mode=WAL`, Loader читает её напрямую.
- **i18n:** тест сверяет ключи и плейсхолдеры четырёх локалей.
