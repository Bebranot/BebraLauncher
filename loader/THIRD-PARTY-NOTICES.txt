BebraLauncher — third-party components shipped with the game Loader
====================================================================

This file lists the third-party software that is packed into the installer inside the
`loader` directory (the .NET game Loader and its native libraries). The licence names are
taken from the NuGet package metadata of the exact versions pinned in
loader/Directory.Packages.props and loader/SS14.Loader/packages.lock.json. Full licence
texts are distributed inside the corresponding NuGet packages.

The LGPL libraries (FluidSynth, OpenAL) are shipped unmodified as separate DLL files and
are loaded dynamically by the game, so they can be replaced by the user.
